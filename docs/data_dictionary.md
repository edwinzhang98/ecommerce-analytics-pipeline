## fct_orders

**One row per order placed on the marketplace, in any status** (99,441 rows). The single source of truth for order counts and order-level revenue, delivery and review outcomes. Placed orders = `count(*)`; **net orders (official KPI) = `count(*) filter (where is_net_order)`**; delivered orders = `count(*) filter (where is_delivered)` (ADR 0002). Date basis: `order_purchase_date`. Rebuilt in full on every run (it holds mutable order state).

- **Grain:** one row per order
- **Rows:** 99,441
- **Update:** Full rebuild on every `dbt build` (`make build`).

## fct_order_items

**One row per unit sold (order line)** (112,650 rows). Item price, freight, product and seller as fixed at purchase, plus the order's current status and `is_net_order`, so item-level sums can be restricted to net orders without a join. **Sum `item_total_brl` only where `is_net_order`** to get net GMV by product, category or seller. **Incremental** (ADR 0005): each run processes new orders (with a `fct_order_items_lookback_days` window) plus every order that was still open at the last run. For delivery or review outcomes, join to `fct_orders` on `order_id` (many-to-one, safe).

- **Grain:** one row per order item (unit)
- **Rows:** 112,650
- **Update:** Incremental (delete+insert on `order_item_key`): new orders since the last load minus a 3-day lookback, plus every order that was still open. See ADR 0005.
- **Built from:** int_orders_joined, order_status_mapping, stg_olist__order_items
- **Model-level tests:** dbt_utils_unique_combination_of_columns_fct_order_items_order_id__order_item_id, fct_order_items_has_one_row_per_source_item, item_gmv_reconciles_with_order_gmv, item_net_gmv_reconciles_with_order_net_gmv
- **Source:** [`dbt/models/marts/core/fct_order_items.sql`](../dbt/models/marts/core/fct_order_items.sql)

## seller_scorecard

**One wide row per seller** for the seller-management team: volume, GMV and concentration (rank, share, cumulative share), fulfilment (late delivery, late handover vs the seller's shipping limit) and review outcomes. Net orders only. Order-level outcomes (delivery, review) are attributed to every seller in a multi-seller order (1.3% of orders). Rates on small sellers are noisy: filter on `net_orders` before ranking.

- **Grain:** one row per seller
- **Rows:** 3,095
- **Update:** Full rebuild on every `dbt build` (`make build`).
- **Built from:** dim_products, dim_sellers, fct_order_items, fct_orders
- **Model-level tests:** seller_gmv_reconciles_with_net_order_gmv, seller_scorecard_has_one_row_per_seller
- **Source:** [`dbt/models/marts/business/seller_scorecard.sql`](../dbt/models/marts/business/seller_scorecard.sql)
